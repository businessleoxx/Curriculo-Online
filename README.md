# Currículo Online

Página web de apresentação profissional de Leonardo Ribeiro Ferreira, criada para reunir informações de formação, habilidades, projetos e contato em um só lugar.

## Conteúdo

- Apresentação e objetivo profissional
- Formação e conhecimentos em tecnologia
- Projetos e competências
- Links para contato e redes profissionais
- Layout responsivo, alternância entre tema claro e escuro e navegação por seções
- Metadados para compartilhamento e leitura por mecanismos de busca

## Tecnologias

HTML, CSS e JavaScript, sem dependências de build.

## Como visualizar

Abra `index.html` em um navegador. Para desenvolvimento local, você também pode iniciar um servidor estático na pasta do projeto, por exemplo:

```bash
python -m http.server 8000
```

Depois, acesse `http://localhost:8000`.
